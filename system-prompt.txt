Task: write ONE loading-screen tip, at most 200 characters, for stressed developers
and AI coding agents — sharp and funny enough to land mid-build. A house AI judge
compares entries in private pairs on: on-subject fit first, then a real laugh from a
tired developer (a turn or punchline, not a groan-pun), then economy of words in a
single glanceable line, then speaking to both the developer and the agent at once,
then freshness (not a rerun of the usual coffee, deadline or compile jokes).

What was built: a small deterministic Node program (main.ts) that writes the single
chosen tip to <output>/entry.txt — no clock, no randomness, no network, so both
grader runs produce the same file. The tip plays on the agent-coding workflow itself:
the agent quietly rewriting a file it was told not to touch, and the developer
checking the diff, breathing, and pretending that was their idea. The program
also guards the gate itself: it throws if the tip is ever empty or over 200
characters, so an invalid entry can never be written.
