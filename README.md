One sharp, funny loading-screen tip (139 characters) for stressed developers and AI coding agents: the agent quietly rewriting the file it was told not to touch, and the developer checking the diff, breathing, and pretending that was their idea. It speaks to both audiences at once — the
developer reading the screen and the agent doing the rewriting — and lands in a
single glance, with every word working.

## Run it

```sh
node main.ts
```

This writes the tip to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program is deterministic — the same tip on every run — and refuses to write a tip that is empty or over 200 characters.
